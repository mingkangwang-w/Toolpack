刷题助手 · 便携版使用说明

1. 将整个「刷题助手」文件夹解压到桌面、文档或其它可写目录。
   不要只复制 exe，也不要放进 Program Files 等需要管理员权限的目录。

2. 双击「刷题助手.exe」。
   程序会启动本地服务，并自动打开浏览器：
   http://127.0.0.1:8765/

3. 保持命令行窗口开着；关闭窗口就会停止程序。
   如果浏览器没有自动打开，可以手动访问上面的地址。

4. 使用过程中会在 exe 旁边生成：
   - 题库保存/       Markdown 题库，请定期备份
   - ai-config.json  AI 配置（包含 API Key，切勿分享）

5. 不需要安装 Python，也不需要联网安装 OCR 依赖。
   只有主动使用 AI 分析或 AI 辅导时才需要联网，并在「AI 设置」中填写自己的 API Key；
   本地 OCR、题库保存和练习不需要 AI。

   要从网页内导出/导入题库：
   打开「我的题库」→「导出题库」，勾选需要的科目或子题库，
   会合并下载为一个 JSON 题库文件。
   对方打开「我的题库」→「导入题库」→「选择 .json / .md 文件」，
   直接选择这个文件即可合并；也可以选择一个或多个 Markdown 文件，
   或直接选择整个题库文件夹。不需要手动把文件复制到 exe 目录。

   如果平板和电脑在同一个 Wi-Fi：
   打开「我的题库」→「分享给平板」→「开始分享」，
   页面会显示电脑地址和 6 位导入码；在平板 App 的
   「配置题库 → 从电脑导入」中输入即可。分享只读，10 分钟后自动停止，
   关闭程序也会停止，不会上传到互联网。

6. 如果 Windows SmartScreen 提示未知发布者：
   点击「更多信息」→「仍要运行」。
   这是未做数字签名的本地程序；图片只在本机做 OCR，只有你主动使用 AI 时才会把对应图片的文字发送给所配置的模型服务。

7. 如果 8765 端口被占用，请先关闭旧的刷题助手进程，或在命令行中运行：
   刷题助手.exe --port 8766

8. 升级版本时，先备份旧目录中的「题库保存」和「ai-config.json」；
   换到新版本目录后，把这两项复制过去即可保留题库和 AI 配置。

9. 删除程序不会自动删除题库文件。确认不再需要时，请手动备份或删除整个文件夹。
