# 刷题助手

把题目截图或照片识别成可练习的题库，按「科目 → 子题库」整理，并自动积累为本地 Markdown 文件。支持单库练习、总题库练习和无限随机模式；题库保存在磁盘，做题时不需要调用 AI。首页提供近 30 天学习时长、刷题数量和按科目/子题库切换的正确率折线图。练习页可以选择显示常驻的 AI 辅导侧栏，做题过程中随时让 AI 提示、讲解或分析错因。界面参考 GitHub 的浅色与深色配色，以中性灰为主，少量使用蓝色、绿色、黄色、紫色、玫红和红色表达操作与状态。本地 OCR 逐张提取文字；可选接入普通 OpenAI 兼容对话模型，只分析提取出的文字，不接收图片。

## 启动

双击 **启动刷题助手.bat**。

- 第一次启动会自动安装本地 OCR 组件，需要联网，约几分钟。
- 启动后浏览器会自动打开 `http://127.0.0.1:8765/`。题目保存在磁盘的 `题库保存/` 文件夹中，换端口仍会加载；练习统计、历史记录和界面设置按浏览器地址隔离，所以仍建议使用默认地址。
- **不要关闭黑色命令行窗口**，它是本地服务；关闭窗口即停止程序。
- 如果第一次自动安装失败，先双击 **安装依赖.bat** 再启动。
- 重复启动时会自动复用已经运行的实例，不会覆盖数据或换端口。

当前电脑已安装好依赖，可以直接启动。

## 使用流程

1. **创建科目**：进入「我的题库」，点击「新建科目」，例如「高等数学」「计算机基础」。
2. **创建子题库**：在科目卡片里点击「新建子题库」，例如「第一章 极限」「第二章 导数」。
3. **导入题目**：在导入页顶部选择本次要保存到的科目和子题库，再上传 PNG / JPG / WebP 截图。支持一次多张、拖拽、拍照，也可以直接在页面按 `Ctrl + V` 粘贴截图。想先试一下，可以直接导入 `示例/示例题目.png`。
4. **识别校对**：自动识别中文和英文，合并换行、拆分题号、选项、答案和解析。识别错的字可以直接在左侧文本框修改，再点击「重新拆题」。
5. **可选 AI 逐图分析**：程序按图片逐张循环，把每张图单独 OCR 出的文字发给 AI 识别、拆分和分析。AI 不接收图片；结果先按图片分组展示，必须由你确认后才替换预览。
6. **保存入库**：在右侧每题校对题型、选项和正确答案。题型支持单选、多选、判断、填空和简答。选择、判断和填空题需要答案才能进入练习；简答题的参考答案仅供参考、可以留空，练习时自行对照评分。保存时如果发现与题库已有题目或本批其他题目重复，会先让你逐题决定保留或跳过。
7. **开始刷题**：从「我的题库」可以直接刷总题库、某个科目的总题库，或单独刷一个子题库。进入练习设置后可以选择本次题数（5 / 10 / 20 / 自定义）、「全部」一次刷完，或选择 ∞「无限」模式持续随机出题。
8. **选择答题方式**：可以选「每题查看答案」或「全部做完后查看」；无限模式固定使用每题查看答案。
9. **复习**：错题自动进入错题本；首页和练习页都可以直接开始错题复习。

### 重复题目

保存导入的题目时，程序会按题干（忽略空格和常见标点）检查重复：

- 与题库中已有题目重复，或与本批其他题目重复时，会弹出「发现重复题目」窗口。
- 每个重复题都有勾选框，默认加入题库；取消勾选后本次保存会跳过该题，题库里已有的原题不会被删除。
- 可以「全部跳过重复题」快速取消所有重复项，或逐题切换；底部按钮会显示实际要加入题库的题数。
- 取消保存会留在预览页，不会写入任何题目。
- 对已经入库的历史重复题，可以在「我的题库」中点击「重复题」筛选查看。重复组管理区提供「忽略提醒，保留在题库」：题目不会被删除，仍可正常查看、练习和抽题，只是不再计入重复提醒。
- 忽略后可以点「在全部题库中查看」确认这些题仍在题库里；需要重新检查时点「恢复重复提醒」。

### 批量操作

题库列表中的每道题左侧都有勾选框：

- 可以逐题勾选，也可以勾选「全选当前结果」；选择数量显示在列表上方。
- **批量编辑**：统一修改所选题目所属的科目、子题库和收藏状态，不会改动题干、选项、答案和解析。单题内容仍用题目右侧的编辑按钮修改。
- **删除选中**：确认后一次删除所选题目，并同步更新 Markdown 题库。
- 切换筛选、搜索或科目/题库范围时，已不在当前结果中的选择会自动移除，避免误操作到看不到的题目。

### 学习统计

首页「学习统计」汇总最近 30 天的数据：

- **学习时长**：练习中实际停留的时间会累计到当天；学习时长从本次更新后开始记录，之前的历史没有时长数据。
- **刷题数量**：最近 30 天完成的作答次数，包含两种答题方式和简答题自评。
- **正确率趋势**：折线图默认显示全部科目，也可以选择某个科目或某个子题库。每次只显示当前选择的一条曲线，不会把所有范围画在一起；切换选择后图表立即更新。
- 正确率按每天实际作答计算；没有作答的日期不显示数据点，折线直接连接前后有数据的日期。把鼠标移到图上或聚焦数据点可以查看当天详情，也可以展开「查看数据表」读取全部数值。
- 按科目和子题库的每日正确率从本次更新后开始记录，新完成的练习会自动归入对应的科目和子题库。统计数据只保存在当前浏览器。

### 答题方式

- **每题查看答案**：单选/判断题点选选项后自动提交，立刻显示正确答案、对错和解析，按「下一题」继续。适合边做边学。
- **全部做完后查看**：答题过程中不显示对错或答案；单选/判断题点选后自动进入下一题，全部完成后统一显示正确率、答对/答错数量和错题答案。适合模拟测试。
- 多选题选择全部正确选项后点提交；填空题填写后按 Enter 或点提交。
- 简答题填写后点「提交并自评」，程序会显示参考答案和解析；你选择「答对了」或「还需复习」后才计入统计。简答题没有唯一文本答案，参考答案仅供对照，可以留空，也不会由程序自动判分。
- 练习过程中可以点「上一题」回看之前的题目和已选项。已作答的题目不会重复计分。
- 答题方式会记住上次的选择，下一次进入练习设置时仍会保持。

### 无限模式

在练习设置的「题目数量」中选择 **∞ 无限**：

- 从当前题库范围的全部可练习题开始，打乱顺序持续出题，没有固定终点，也不会自动交卷。
- 一轮题刷完后会重新打乱并继续循环，同一道题可能再次出现。
- 只能点击「退出练习」手动结束；有作答记录时会先确认，并显示本轮正确率、答对/答错、用时和错题。
- 无限模式固定使用随机顺序和「每题查看答案」，因此不会出现“全部做完后查看”。
- 右侧进度点只显示最近 24 题；总出题数不受限制。
- 无限模式和 AI 侧栏的开关会记住上次选择，下次进入练习设置时保持不变。

### 练习中的 AI 侧栏

练习页右侧会常驻一个「AI 辅导」对话区，做题过程中可以随时提问：

- 可以让 AI 给提示、讲思路、分析错因、换一种讲法或出同类题；也可以直接输入自己的问题。
- 对话会结合当前题目、选项、答案、解析和你的作答状态。它不会看到图片，只接收文字。
- AI 只在点击快捷问题或发送消息时调用，不会在开始练习时自动产生模型费用。
- 切换题目或提交答案后，侧栏会保留聊天记录，并用新题目继续回答。
- 窗口较窄时，AI 面板会移到题目下方；点题目右上角的「AI 辅导」可定位到输入框。
- AI 侧栏是可选的：练习设置中的「AI 辅导」开关可以默认关闭侧栏；答题时也可以点侧栏右上角的关闭按钮隐藏，再点题目右上角的「显示 AI 辅导」重新打开。这个选择会被记住。
- 没有配置 AI 时，侧栏会显示配置入口，不影响刷题、本地 OCR 和题目解析；关闭侧栏时不会读取 AI 配置，也不会调用 AI。

键盘作答：`A`–`D` 或 `1`–`4` 选择选项，`Enter` 提交 / 下一题；简答题输入框内用 `Ctrl + Enter`（macOS 为 `Cmd + Enter`）提交并进入自评。

## 科目、子题库与总题库

题库按两层组织：

```text
总题库（所有科目）
├─ 科目 A
│  ├─ 科目 A 总题库
│  ├─ 子题库 A-1
│  └─ 子题库 A-2
└─ 科目 B
   ├─ 科目 B 总题库
   └─ 子题库 B-1
```

- 「总题库」汇总所有科目的题目；每个科目也有自己的「科目总题库」。
- 每个子题库、科目总题库、总题库都可以单独开始练习。
- 子题库默认按创建时间排序；拖动子题库左侧的拖动手柄可以自定义顺序，拖动结果会写入 Markdown 并保持。聚焦拖动手柄后也可以按上下方向键调整。
- 自定义顺序优先于创建时间，不会因为 Markdown 文件名按字符排序而出现「10」排在「2」前面的情况。
- 练习设置里可以选择题数，也可以选择「全部」把当前范围的题目一次刷完。
- 题目编辑弹窗里可以修改题目所属的科目和子题库。
- 「总题库」卡片固定在左侧；右侧科目与子题库列表有独立的最大高度，内容较多时只滚动科目区域，不会把页面撑得过长。滚动时科目标题保持可见。
- 删除科目或子题库前，需要先清空其中的题目；旧版本题目会自动迁移到「未分类科目 / 未分类题库」。

## Markdown 题库文件

创建科目和子题库后，程序会在项目下的 `题库保存/` 目录中建立科目文件夹；**每个子题库直接保存为该文件夹下的一个 `.md` 文件**：

```text
题库保存/
└─ 高等数学/
   ├─ .shuati-subject.json   隐藏的科目索引，用于保持题库 ID
   ├─ 第一章 极限.md
   └─ 第二章 导数.md
```

文件夹名就是科目名，Markdown 文件名就是子题库名。只要把符合格式的 `.md` 文件放入某个科目文件夹，应用启动或刷新时就会把它加入该科目。题目正文是可读的 Markdown，少量机器元数据放在 HTML 注释里：

```md
<!-- shuati:question:start -->
## 第 1 题 · 单选题

**题目**

当 x→0 时，sin x / x 的极限是多少？

**选项**

- A. 0
- B. 1
- C. ∞
- D. 不存在

**答案**

B

**解析**

这是重要极限。
<!-- shuati:question:end -->
```

这些文件就是系统积累的题库：

- 保存、编辑、移动或应用 AI 结果后，应用会自动重写对应的 Markdown 文件。
- 每次启动应用会扫描 `题库保存/`，科目来自文件夹，子题库来自其中的 `.md` 文件；练习时只从本地题库抽题，**不会调用 AI**。
- 可以直接在 `题库保存/` 中新建科目文件夹和放入新的题库 MD；重新载入后即可生成对应科目和子题库。
- AI 只用于导入新图片时的文字结构分析，不是刷题的前置条件。
- 可以手动修改题目文字、选项、答案和解析，然后在「数据备份」中点击「从磁盘刷新」重新读取；结构标记和 `<!-- shuati:... -->` 注释建议保留。Markdown 文件需使用 UTF-8 编码，非 UTF-8 文件会提示转码，不会被自动覆盖。
- 复制同一个受管子题库 `.md` 作为副本时，程序会为副本中的重复题目生成新 ID，不会静默丢弃副本内容。
- 简答题在 Markdown 中使用 `## 第 N 题 · 简答题` 标题，选项写为 `_（无选项）_`；参考答案或评分要点可选，写入 `**答案**` 后仅供练习时对照。
- 删除科目或子题库时只会清理程序管理的 Markdown 文件；同一文件夹中的图片、笔记等非管理文件会保留。
- 旧版浏览器题库会在第一次启动时自动写入新结构；源图片可以继续放在单独的 `题库导入/` 文件夹中，应用不会把它们当成题库。

## AI 逐图分析

AI 是可选增强，不影响本地 OCR 使用。处理顺序固定为：

```text
图片 1 → 本地 OCR → 图片 1 的独立文字 → AI 分析
图片 2 → 本地 OCR → 图片 2 的独立文字 → AI 分析
……
```

**AI 始终不接收图片。** 它只接收每张图片单独提取出的 OCR 文字，并在自己的文字范围内识别、纠错和拆分题目，不跨图片合并。

### AI 配置教学

AI 是可选的。没有配置 AI 时，本地 OCR、拆题、保存题库和练习都能正常使用；只有主动点击 AI 相关按钮才会调用模型并产生费用。

#### 第一步：准备 API Key

AI 分析需要一个支持 **OpenAI 兼容 Chat Completions 接口** 的普通对话模型。网页版聊天会员账号通常不能直接当 API 使用，需要到服务商的开发者控制台创建 API Key：

1. 登录所选服务商的控制台。
2. 找到「API Key」「密钥管理」或类似入口，创建一个新密钥。
3. 复制保存密钥；很多服务商只会在创建时完整显示一次。
4. 确认账号有可用额度或已绑定计费方式。
5. 确认服务商文档中提供了 **OpenAI 兼容接口地址** 和 **对话模型名称**。

本地模型（例如 LM Studio、Ollama）通常不需要 API Key 或计费，填写本地接口地址和模型名即可。不要把账号密码、网页登录 Cookie 或别人的共享 Key 填进这里。

#### 第二步：在应用中填写

1. 启动刷题助手，打开 `http://127.0.0.1:8765/`。
2. 点击左侧「AI 设置」。
3. 填写「接口地址」：
   - 可以填服务商提供的 base URL，例如 `https://api.openai.com/v1`。
   - 也可以直接填完整的 `/chat/completions` 地址。
   - 程序会自动补全常见的 `/chat/completions` 路径；远程服务请使用 `https://`。
4. 填写「API Key」。如果之前已经保存过，输入框留空会保留原密钥；本地模型不需要鉴权时可以留空。
5. 填写「模型名称」。必须是服务商提供的普通对话模型名称，不需要 OCR 模型，也不需要支持图片输入。
6. 可选：填写「运行规则与指导」，调整回答风格、术语偏好和核验习惯。
7. 点击「测试连接」。看到连接成功后点击「保存」。
8. 回到导入页，点击「AI 逐图分析」开始使用。

#### 第三步：确认调用方式和费用

- 程序会对每张图片分别执行：本地 OCR → 单独把这张图的文字发给 AI。**图片永远不会发给 AI。**
- 每轮 AI 分析前都会再次确认；AI 结果只进入预览，不会自动写入题库，需要你校对后保存。
- 失败页不会阻塞其他图片；可以点「重试失败项」只重试失败页面。
- 费用、限流和每日额度由你选择的服务商决定。建议先用几张图片测试，再批量导入。

#### 常见服务商示例

| 服务 | 接口地址示例 | 模型名称 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/chat/completions` | 例如 `deepseek-flash`，以服务商当前文档为准 |
| OpenAI | `https://api.openai.com/v1` | 按账号可用模型填写 |
| 阿里云百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 按服务商文档选择通义千问对话模型 |
| 智谱 AI | `https://open.bigmodel.cn/api/paas/v4` | 按服务商文档选择 GLM 对话模型 |
| 本地 LM Studio | `http://127.0.0.1:1234/v1` | 本地加载的对话模型 |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | 本地加载的对话模型 |

以上地址只演示格式，模型名称和服务商限制可能变化，请以服务商当前文档为准。DeepSeek 可以在 AI 设置里点「一键填入 DeepSeek 配置」，再填写自己的 API Key。

#### 常见配置问题

| 现象 | 可能原因和处理 |
| --- | --- |
| 401 / 403 | API Key 填错、已失效、没有权限，或账号/地区不支持；重新创建 Key，确认额度。 |
| 404 | 接口地址错误，常见原因是缺少 `/v1` 或把完整地址重复拼接；对照服务商文档检查。 |
| 429 | 请求过快、额度不足或触发限流；等待后重试，或换用额度更充足的模型。 |
| model not found | 模型名称拼写错误，或该账号没有这个模型的权限；使用服务商控制台显示的准确名称。 |
| 请求超时 / 网络错误 | 检查网络、代理和防火墙；远程服务优先使用 HTTPS，本地模型确认服务已经启动。 |
| 返回内容不是 JSON | 模型指令遵循能力不足或输出被截断；换用普通对话模型，减少单页文字长度后重试。 |
| 测试连接成功，但逐图分析失败 | 可能是单页文字过长、限流、额度或模型输出异常；查看对应图片文件卡片上的失败原因，只重试失败项。 |

#### 运行规则与指导（可选）

AI 设置中的自定义规则最多 8000 字，会附加到以下所有 AI 场景：

- 逐图文字分析
- 练习页 AI 辅导
- 全局 AI 助手
- 题库巡检和导入决策

适合写入回答风格、学科术语偏好、答案解析要求和核验习惯。自定义规则只能补充偏好，不能覆盖「AI 不接收图片」、来源真实性、动作白名单、数据修改确认等系统约束；冲突时以系统规则为准。规则只保存在本机 `ai-config.json` 中，不会进入题库备份。

#### API Key 安全

- API Key 只保存在本机项目的 `ai-config.json` 中，不会写入 Markdown 题库，也不会进入题库备份。
- `ai-config.json` 默认已被 `.gitignore` 忽略，不要截图、上传或发给别人。
- 如果密钥曾经泄露，请立即到服务商控制台撤销并重新创建。
- 远程模型会接收每张图片的文字内容；如果题目涉及隐私，建议使用本地模型，或不要使用 AI 分析。

### 逐图分析的特点

- 每张图片在列表里都有独立的 `AI 排队中 / AI 分析中 / AI 已分析 / AI 分析失败` 状态。
- 任意一张 AI 调用失败不会阻塞后续图片；失败页会在结果中单独标记。图片较多时会在请求之间留出间隔，服务商限流、临时 5xx 或网络中断会自动退避重试。
- 分析结束后如果仍有失败页，会显示「重试失败项 (N)」按钮，只重新发送失败图片的文字，不会重复调用已经成功的页面。
- 失败原因会显示在对应文件卡片上，并写入 AI 结果中的页面警告，便于判断是限流、超时、模型配置还是文字过长。
- 带页面警告、题目警告或置信度低于 70% 的 AI 题目，保存后会在题库列表显示黄色「AI 需复核」标记；标记会随 Markdown 保存。打开题目编辑可查看来源图片、警告和置信度，确认无误后可清除标记。
- 应用 AI 结果时只替换右侧题目预览，不直接写入题库；你仍然需要校对并点击保存。
- AI 看不到原图，所以无法独立验证 OCR 是否真的看错。提示词会要求它只根据文字纠正明显问题，不能确定的地方必须写入警告，不允许补造答案。

### 答案冲突与联网核验

当 OCR 文字中的题干、选项与标注答案出现明显冲突时，提示词要求 AI：

- 先在这张图片自己的文字范围内反复核对。
- 如果配置的模型或服务**本身支持联网搜索**，可以自主搜索简洁关键词，优先查证权威教材、标准和官方网站；来源名称或 URL 必须写入该题的警告。
- 只有检索证据明确支持时才允许修正答案，并在警告中写明原答案、冲突点和依据。
- 不能联网、搜索无结果或来源矛盾时，必须保留原答案、降低置信度并说明冲突；不得声称已经搜索，也不得编造来源。

注意：DeepSeek、OpenAI 的普通对话 API 默认不具备网页搜索能力；是否能真正联网取决于模型和服务商。若需要强制联网核验，需要选择带搜索能力的模型服务或单独接入搜索 API。使用带搜索能力的模型时，检索关键词会由该模型服务处理；图片仍然不会发送。

### AI 选项式互动

启用 AI 后，应用提供类似 Claude Code 的可点击选项交互：

- 右下角「AI 助手」：根据当前页面提供下一步操作选项，也可以直接文字提问。
- 刷题页右侧「AI 辅导」侧栏：AI 会根据当前题目给出“提示 / 讲解 / 错因分析 / 同类题”等动态选项，也可以自由输入问题。
- 题库页「AI 巡检」：根据缺答案、重复题、答案异常统计，提供查看筛选的选项。
- 导入结果页「让 AI 帮我决定」：AI 根据逐图分析结果给出应用、逐题查看或重新分析的选项。

AI 会动态生成选项，但选项动作受白名单约束；AI 不能直接删除、改写或保存数据。需要修改界面的动作由你在点击选项后执行，危险操作仍走应用自己的确认流程。

### 关于“周期”

当前实现是：点击一次「AI 逐图分析」后，在一个任务内按图片顺序循环处理，直到所有图片完成或跳过。它不是后台定时任务，也不会在你不操作时自动产生 API 费用。

如果你希望定时扫描图片文件夹（例如「题库导入/」）中的新图片并自动执行这条 AI 周期，需要另外确定目录、扫描间隔和失败重试策略，再接入后台定时任务。

### 安全与限制

- AI Key 和自定义运行规则保存在本机项目根目录的 `ai-config.json`，是明文本地配置文件，不会进入题库 JSON 备份。
- AI 只接收提取出的文字，不接收图片；普通 OCR 完全在本机运行。
- AI 可能拆错题或根据上下文“纠正”错字。应用前请检查置信度、警告和题目内容。
- 练习侧栏提问时，会发送当前题目的文字、选项、答案、解析和你的作答状态给 AI（不发送图片）；这些内容用于生成提示、讲解和错因分析。
- 如更换了服务商，建议在 AI 设置中重新填写 Key；不再使用时可删除 `ai-config.json`。

## 数据保存

- 科目、子题库、题目、答案和解析保存为项目 `题库保存/` 文件夹中的 Markdown 文件；科目对应文件夹，每个子题库对应一份独立 `.md` 文件。AI 复核警告、置信度和来源图片信息也保存在题目元数据中。
- 练习统计、错题状态和历史记录保存在**当前浏览器的本地存储**中，并按浏览器地址隔离；换浏览器或端口后题目仍在，但练习进度不会自动迁移。
- **图片本身不会被保存，也不会发送给 AI**。图片只交给本机 OCR；AI 只接收每张图片单独提取出的文字。
- 「数据备份」可以导出 / 导入包含科目、子题库、题目、练习记录和统计的完整 JSON；它是 Markdown 题库之外的额外备份。导入时内容相同的题目不会重复添加，并会合并备份中的练习统计和收藏状态。
- 在「数据备份」里点击「从磁盘刷新」可以重新读取手动修改过的 Markdown 文件。
- 清除浏览器数据只会影响练习统计和设置，不会删除 Markdown 题库；「清空数据」会同时清理程序管理的题库 Markdown 文件，但保留同目录下的图片等非管理文件。建议操作前先导出 JSON 备份。

## 识别说明与限制

- RapidOCR 对清晰的截图、白底印刷体效果最好。
- 彩色或小字号的孤立答案字母容易因置信度偏低被过滤；现在会保留疑似答案的低置信度字母和「正确 / 错误」文字，并过滤其余低置信度噪声。
- 手机作业截图中的时间栏、页码导航和「教师批阅」会自动忽略；「正确答案 C，我的答案：A」会提取 C 作为正确答案，不会用“我的答案”覆盖。全角答案字母也会自动转成半角。
- 手写体、艺术字、复杂公式、上下标、双栏排版可能需要手动校对。
- 数学公式目前按普通文本识别，建议在预览区手动修正。
- 单张图片最大 25MB，单批最多 100 张；超过 100 张时会提示未加入的数量，可以分批导入。
- 题目解析依赖题号、选项字母和「答案：」「解析：」等常见格式；格式特殊时可在预览中手动调整。

## 隐私

- 服务只绑定 `127.0.0.1`，不监听局域网；所有写接口只接受同源页面发起的 `application/json` 请求，拒绝其他网页的跨站调用。
- 普通识别时，图片只在 `POST /api/ocr` 中发送给本机 Python 服务处理，处理完不落盘。
- AI 永远不接收图片。导入时，只有每张图片单独 OCR 出的文字会经本机服务转发到你配置的普通对话模型服务；每轮发送前都有确认提示。
- 如果所选模型服务自带联网搜索，答案冲突核验时检索关键词会由该模型服务处理；程序本身不会另行上传题目或图片。
- 练习侧栏中只有你主动提问时才会调用 AI，发送当前题目的文字上下文和对话记录，不包含图片；不提问就不会产生调用。
- AI 设置中的自定义运行规则会作为系统提示的一部分发送给你配置的模型服务，并且只保存在本机 `ai-config.json`。
- AI 配置文件 `ai-config.json`（包含 Key 和自定义运行规则）只保存在本机，不进入题库备份。
- 没有账号、云同步或遥测。
