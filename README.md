# 刷题助手

把题目截图或照片识别成可练习的题库，按「科目 → 子题库」整理，并自动积累为本地 Markdown 文件。支持单库练习、总题库练习和无限随机模式；题库保存在磁盘，做题时不需要调用 AI。首页提供今日学习时长、近 30 天每日学习时长柱状图、刷题数量，以及只按完整练习计算、可切换科目/子题库的正确率统计。练习页可以选择显示常驻的 AI 辅导侧栏，做题过程中随时让 AI 提示、讲解或分析错因。电脑端还可以按子题库用 AI 归纳树状知识图谱，结果以 JSON 保存在题库保存目录；图谱节点会关联真实题目和本地掌握度。界面参考 GitHub 的浅色与深色配色，以中性灰为主，少量使用蓝色、绿色、黄色、紫色、玫红和红色表达操作与状态。本地 OCR 逐张提取文字；可选接入普通 OpenAI 兼容对话模型，只分析提取出的文字，不接收图片。

## 启动

双击 **启动刷题助手.bat**。

- 如果拿到的是便携版，直接双击其中的 `刷题助手.exe`，不需要安装 Python；见下文「给其他人使用：便携版」。
- 第一次启动会自动安装本地 OCR 组件，需要联网，约几分钟。
- 启动后浏览器会自动打开 `http://127.0.0.1:8765/`。题目保存在磁盘的 `题库保存/` 文件夹中，换端口仍会加载；练习统计、历史记录和界面设置按浏览器地址隔离，所以仍建议使用默认地址。
- **不要关闭黑色命令行窗口**，它是本地服务；关闭窗口即停止程序。
- 如果第一次自动安装失败，先双击 **安装依赖.bat** 再启动。
- 重复启动时会自动复用已经运行的实例，不会覆盖数据或换端口。

当前电脑已安装好依赖，可以直接启动。

## 给其他人使用：便携版（无需安装 Python）

如果要把软件交给其他人使用，不需要让对方安装 Python。构建好的便携版位于：

```text
windows/release/
├─ 刷题助手/
│  ├─ 刷题助手.exe
│  ├─ _internal/                  运行库、OCR 模型和网页资源
│  └─ 便携版使用说明.txt
├─ 刷题助手-便携版.zip            干净包，不含题库和 AI Key
└─ 刷题助手-含题库-便携版.zip     含题库和隐藏的知识图谱 JSON
```

把 **`刷题助手-便携版.zip`** 发给对方，解压后双击 `刷题助手.exe` 即可：

- 不需要安装 Python，也不需要手动安装 OCR 依赖。
- 第一次运行会在 exe 旁边生成 `题库保存/`；保存 AI 设置后会生成 `ai-config.json`。
- 便携版不包含构建者的题库、图片和 AI Key，请勿把 `ai-config.json` 打进分发包。
- 建议解压到桌面、文档等可写目录，不要放在 `Program Files`。
- 因为程序未做数字签名，Windows SmartScreen 可能提示未知发布者，选择「更多信息 → 仍要运行」即可。
- 便携版可以正常读取和写入 Markdown 题库，但它不会打开任意位置的单个 `.md` 文件；它只扫描 exe 同级的 `题库保存/科目名/*.md`。复制题库后请重启 exe，不要放进 `_internal/`。便携版不提供独立的 Markdown 编辑器，读取后的内容会按题库界面展示。

维护者需要重新打包时，双击项目根目录的：

```text
windows/构建便携版.bat
```

脚本会检查依赖、安装 PyInstaller、清理旧构建，并生成新的 `windows/release/刷题助手/`、不含题库的干净 zip 和含题库 zip。干净包会排除 `题库保存/`、`ai-config.json` 和证书；含题库包会显式带上 `题库保存/.shuati-knowledge/` 里的知识图谱 JSON，分享前请确认内容。打包使用同一台 Windows 电脑上的 Python 和 OCR 依赖，不需要在目标电脑安装。`windows/release/` 和 `build/` 已被 `.gitignore` 忽略；如果要发布到 GitHub，建议把 zip 作为 Release 附件上传，不要提交到仓库。

## 分享题库给其他人

题库和程序是分开的：`刷题助手.exe` 只是程序，真正的题目在 `题库保存/` 中。分享前请关闭正在运行的刷题助手，避免程序同时改写文件。

#### 方式一：便携版 + 题库（推荐给还没有软件的人）

1. 复制一份 `windows/release/刷题助手/` 文件夹，改名为例如 `刷题助手-分享版/`。
2. 把自己的 `题库保存/` 文件夹整个复制到这个分享版文件夹中，与 `刷题助手.exe` 同级。
3. **不要复制 `ai-config.json`**，否则会把你的 API Key 一起发出去。
4. 把整个文件夹压缩成 zip 发给对方。
5. 对方解压后双击 `刷题助手.exe`，启动时会读取随附的 `题库保存/`。

目录结构应类似：

```text
刷题助手-分享版/
├─ 刷题助手.exe
├─ _internal/
└─ 题库保存/
   └─ 科目名/
      ├─ .shuati-subject.json
      └─ 子题库.md
```

如果只想分享部分内容，只复制对应的科目文件夹即可；科目文件夹名就是分享后的科目名。

#### 方式二：发送一个题库文件（推荐，可选择范围）

在「我的题库」点击「导出题库」，勾选要分享的科目或子题库，再点「导出为一个文件」，会得到一个 `.json` 题库文件。把这个文件发给对方即可。

对方打开「我的题库」→「导入题库」→「选择 .json / .md 文件」，直接选择该文件。文件包含科目/子题库结构、题目、答案、解析、收藏、AI 复核标记和每道题的练习统计；不包含每日学习历史、完整练习正确率记录、AI Key 或图片。导入会合并重复题目，不会清空或覆盖已有题库。

#### 方式三：只发送 Markdown 题库（兼容旧题库）

把 `题库保存/` 文件夹压缩后发送。对方关闭程序，把其中的科目文件夹放进自己的 `题库保存/`，再启动或从「数据备份 → 从磁盘刷新」重新读取。

注意：

- 这种方式只包含题目、答案、解析、收藏和 AI 复核标记，不包含练习统计和历史记录。
- 如果对方已经有同名科目/子题库，直接覆盖文件夹可能混在一起。建议先备份，或改用方式四的 JSON 完整备份进行合并。
- 保留 `.shuati-subject.json` 可以让科目 ID 保持稳定；不要删除。

#### 方式四：JSON 完整备份（包含全部历史，适合迁移整台电脑）

在「数据备份」中点击「导出备份」，会生成一个包含全部数据的 JSON 文件。它包含：

- 科目、子题库、题目、答案和解析
- 题目练习统计、错题状态、每日学习历史和完整练习正确率记录
- 收藏状态和 AI 复核警告
- 不包含 AI Key、`ai-config.json` 或原始图片

对方在「数据备份」中选择「选择文件」导入 JSON。导入会按题目 ID 和内容合并：重复题目不会被重复添加，已有的练习统计和历史会合并。这种方式适合在自己的多台电脑之间同步，或迁移全部数据。

#### 分享后如何持续更新

- 小范围更新可以继续发送新的 `题库保存/` 或 JSON 备份。
- Markdown 题库可以直接用 Git 管理，适合你和对方都熟悉 Git 的情况。
- 当前程序不是多人实时协作系统。不要两个人同时编辑同一个共享文件夹，否则可能互相覆盖；建议指定一个人维护题库，其他人只接收更新。

#### 不要分享的文件

- `ai-config.json`（包含 API Key）
- `题库导入/` 中的私人图片（除非你确实要分享）
- 浏览器本地练习记录只存在于浏览器，不在 Markdown 中；需要迁移时用 JSON 备份

### 从网页导出与导入题库

打开「我的题库」，顶部有「导入题库」和「导出题库」：

- **导出题库**：点击后勾选要导出的科目或子题库，支持「全选」和「清空」；所有选中内容会合并成一个 `.json` 文件下载。文件包含科目/子题库结构、题目、选项、答案、解析、收藏、AI 复核标记和每道题的练习统计；不包含每日学习历史、完整练习正确率记录、AI Key 或原始图片。
- **导入题库**：点击「导入题库」→「选择 .json / .md 文件」，直接选择本地文件即可合并到当前题库。JSON 题库文件一次选择一个；也可以选择一个或多个 `.md` 文件，或选择整个题库文件夹。
- 导入会合并重复题目，不会清空或覆盖已有题库；已有题目的练习统计会合并。

Markdown 导入规则：

- 文件由刷题助手生成时，会优先使用文件元数据中的科目名；文件夹导入时也可以根据文件夹名确定科目。
- 没有科目信息的普通 Markdown 会放入「导入题库」科目，之后可以用批量编辑移动到其它科目。
- 子题库名使用文件名（例如 `第二章.md` → 子题库「第二章」）。
- Markdown 只包含题目、答案、解析、收藏和 AI 复核信息，不包含练习统计和历史记录。
- 一次最多 500 个文件、总大小 20MB。
- 需要连每日学习历史和完整练习正确率记录一起迁移时，使用「数据备份」中的完整 JSON 备份。

这些功能在源码版和便携版中都可用；便携版不需要再把文件复制到 exe 目录，直接在网页里选择文件即可。

## 平板离线版（PWA）

平板离线版用于「电脑端导出题库 → 平板导入 → 断开网络独立刷题」。题目、练习统计和错题都保存在平板浏览器本地，练习过程不访问电脑、不调用 AI。

第一版包含：题库浏览、全部练习模式、收藏、错题、学习统计和正确率记录，并支持导入电脑端导出的知识树（只导入和浏览，不调用 AI）。不包含图片 OCR、AI 辅导、Markdown 导入和磁盘同步。

首次配置可以在概览点击「开始配置题库」，按三步向导操作：电脑端准备 JSON 文件 → 平板选择文件导入 → 查看导入结果并开始刷题。导入后也可以在「我的题库 → 配置向导」重新打开。

### 构建与预览

```bash
py build_offline.py
# 或双击 pwa/构建离线版.bat
```

输出目录为 `dist-offline/`。本地预览：

```bash
py -m http.server 8770 --directory dist-offline
# 打开 http://127.0.0.1:8770/
```

Service Worker 只在 `localhost` 或 HTTPS 下生效。如果要把 `dist-offline/` 部署到公网，可以使用任意 HTTPS 静态站点（例如 Cloudflare Pages、自己的 HTTPS 服务器或 NAS），然后在平板浏览器中打开并选择「添加到主屏幕」/「安装应用」。首次安装需要联网，安装完成后可以完全断网刷题。

#### 不使用外网：局域网安装（HTTP 安装页 + HTTPS 应用，iPad / Android）

浏览器只允许在 HTTPS（或 localhost）下安装离线 PWA，所以局域网安装需要一个本地证书。电脑和安装平板连接同一个 Wi-Fi/局域网后：

1. 双击 `pwa/局域网安装离线版.bat`。脚本会构建 `dist-offline/`，同时启动：
   - HTTP 安装页：`http://电脑局域网IP:8080/install`（8080 被占用时自动用 8081 等，以窗口为准）
   - HTTPS 应用：`https://电脑局域网IP:8443/`
   并自动打开电脑上的「安装二维码」页面。
2. 用 iPad 相机扫描二维码，或手动在平板浏览器打开 HTTP 安装页。安装页使用 HTTP，第一次打开不会遇到证书警告。
3. **iPad / iPhone**：点击「安装刷题助手」。组合描述文件里同时包含本地 CA 证书和主屏幕图标；安装后到「设置 → 通用 → 关于本机 → 证书信任设置」开启完全信任。主屏幕通常会自动出现「刷题助手」；没有出现时用 Safari 打开 HTTPS 应用地址，手动「添加到主屏幕」。
4. **Android**：在 HTTP 安装页下载 CA 证书 →「设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书」，再在 Chrome 打开 HTTPS 应用地址并选择「安装应用」/「添加到主屏幕」。
5. 安装并缓存完成后，可以关闭电脑上的安装服务并断网；平板从主屏幕打开即可刷题。

注意：

- 安装服务只提供 `dist-offline/` 静态文件，不提供题库和 AI Key。
- 本地 CA 私钥保存在电脑的 `offline-certs/`，该目录已被 Git 忽略；不要把它发给别人。
- 平板需要信任一次本地 CA。安装完成后如果不再更新，可以在平板上删除该证书。
- PWA 的本地数据绑定 `https://电脑IP:8443` 这个地址。电脑 IP 变化会导致平板把它当成新站点、看不到旧数据；建议在路由器里给电脑保留固定 IP，或继续使用同一地址安装和更新。
- 如果平板打不开，检查电脑防火墙是否允许 Python 的专用网络访问（安装页端口和 8443 端口），并确认平板和电脑在同一网段。
- 个别 Android 设备或浏览器可能不允许用户安装的 CA 注册 Service Worker；遇到这种情况可以改用后续的 Android APK 方案。

### 数据流转

- 电脑端「我的题库 → 导出题库」勾选需要的科目或子题库，导出一个 JSON 文件。
- 平板打开「我的题库 → 导入题库 → 选择 .json 文件」，题目会保存在平板本地。
- 平板端的练习统计、错题和完整练习正确率记录保存在当前浏览器；换浏览器、清除网站数据或卸载 PWA 会丢失，建议定期导出备份。
- 需要把平板练习结果带回电脑时，在平板导出题库或完整备份，再在电脑端导入。平板和电脑的统计是分开的，通过文件手动合并。
- 「导出题库」包含每道题的练习统计，不包含每日学习历史和完整练习正确率记录；需要这些数据时使用「数据备份」中的完整备份。

当前限制：离线版第一版把题库和统计保存在浏览器本地存储中，适合当前几千道题以内的规模；如果后续题量很大，会迁移到 IndexedDB。平板端暂不支持拍照识题，需要新题时仍在电脑端导入。

### Android / iPad 安装包

- **Android APK**：已生成 `android/release/刷题助手-Android.apk`，可以直接传到 Android 平板安装。应用内置离线网页，不需要浏览器、PWA 安装或局域网证书。
- **iPad**：iOS 工程已生成在 `ios/`，但安装包必须在 Mac + Xcode 上签名构建，步骤见 [ios/构建iPad版.md](ios/构建iPad版.md) 和详细的 [ios/苹果安装手册.md](ios/苹果安装手册.md)。也可以把 `ios/release/刷题助手-iPad-工程.zip` 复制到 Mac，解压后按文档构建。
- Android 后续重新构建：运行 `android/构建Android版.bat`，需要 JDK 17 和 Android SDK。脚本会构建 `dist-offline/`、同步 Capacitor 工程并输出 `android/release/刷题助手-Android.apk`。
- Android 导入题库有两种方式：
  1. 本地文件：电脑「导出题库」得到 JSON，传到平板后在 App 中选择文件导入；不需要网络。
  2. 局域网：电脑打开「我的题库 → 分享给平板」，点击「开始分享」，把页面显示的地址和 6 位导入码输入平板 App 的「配置题库 → 从电脑导入」。只有导入时需要同一 Wi-Fi。也可以双击 `tools/题库分享给平板.bat` 使用命令行方式。
- iPad 同样支持本地文件和局域网导入；局域网导入需要允许 iPad 的本地网络权限。
- Android 使用本地 release 签名密钥，密钥文件在 `android/keystore/` 和 `android/keystore.properties`（已忽略，不进仓库）。后续更新 APK 必须保留并使用同一份密钥，否则无法覆盖安装。

### 软件内「分享给平板」

电脑端打开「我的题库 → 分享给平板」：

1. 点击「开始分享」，软件会启动一个临时只读分享服务，并显示局域网地址和 6 位导入码。
2. 平板 App 进入「我的题库 → 配置向导 → 从电脑导入」，输入地址和导入码。
3. 导入完成后回到电脑点击「停止分享」。

分享默认 10 分钟后自动停止；关闭分享弹窗不会停止，关闭刷题助手会停止。分享服务只读、不包含 AI Key，也不会把题库上传到互联网。局域网分享只同步题库内容，不包含电脑上的练习统计；需要保留统计时请用「导出题库」生成的 JSON 文件导入。如果平板连不上，请允许 Windows 防火墙的「专用网络」访问。命令行用户仍可使用 `tools/题库分享给平板.bat`。

## 使用流程

1. **创建科目**：进入「我的题库」，点击「新建科目」，例如「高等数学」「计算机基础」。
2. **创建子题库**：在科目卡片里点击「新建子题库」，例如「第一章 极限」「第二章 导数」。
3. **导入题目**：在导入页顶部选择本次要保存到的科目和子题库，再上传 PNG / JPG / WebP 截图。支持一次多张、拖拽、拍照，也可以直接在页面按 `Ctrl + V` 粘贴截图。想先试一下，可以直接导入 `示例/示例题目.png`。
4. **识别校对**：自动识别中文和英文，合并换行、拆分题号、选项、答案和解析。识别错的字可以直接在左侧文本框修改，再点击「重新拆题」。
5. **可选 AI 逐图分析**：程序按图片逐张循环，把每张图单独 OCR 出的文字发给 AI 识别、拆分和分析。AI 不接收图片；结果先按图片分组展示，必须由你确认后才替换预览。
6. **保存入库**：在右侧每题校对题型、选项和正确答案。题型支持单选、多选、判断、填空和简答。选择、判断和填空题需要答案才能进入练习；简答题的参考答案仅供参考、可以留空，练习时自行对照评分。保存时如果发现与题库已有题目或本批其他题目重复，会先让你逐题决定保留或跳过。
7. **开始刷题**：从「我的题库」可以直接刷总题库、某个科目的总题库，或单独刷一个子题库。进入练习设置后可以选择本次题数（5 / 10 / 20 / 自定义）、「全部」一次刷完，或选择 ∞「无限」模式持续随机出题。
8. **选择答题方式**：可以选「每题查看答案」或「全部做完后查看」；无限模式固定使用每题查看答案。
9. **复习**：错题自动进入错题本；首页和练习页都可以直接开始错题复习。

### 重复题目

保存导入的题目时，程序会按题干（忽略空格和常见标点）检查重复：

- 与题库中已有题目重复，或与本批其他题目重复时，会弹出「发现重复题目」窗口。
- 每个重复题都有勾选框，默认加入题库；取消勾选后本次保存会跳过该题，题库里已有的原题不会被删除。
- 可以「全部跳过重复题」快速取消所有重复项，或逐题切换；底部按钮会显示实际要加入题库的题数。
- 取消保存会留在预览页，不会写入任何题目。
- 对已经入库的历史重复题，可以在「我的题库」中点击「重复题」筛选查看。重复组管理区提供「忽略提醒，保留在题库」：题目不会被删除，仍可正常查看、练习和抽题，只是不再计入重复提醒。
- 忽略后可以点「在全部题库中查看」确认这些题仍在题库里；需要重新检查时点「恢复重复提醒」。

### 批量操作

题库列表中的每道题左侧都有勾选框：

- 可以逐题勾选，也可以勾选「全选当前结果」；选择数量显示在列表上方。
- **批量编辑**：统一修改所选题目所属的科目、子题库和收藏状态，不会改动题干、选项、答案和解析。单题内容仍用题目右侧的编辑按钮修改。
- **删除选中**：确认后一次删除所选题目，并同步更新 Markdown 题库。
- 切换筛选、搜索或科目/题库范围时，已不在当前结果中的选择会自动移除，避免误操作到看不到的题目。

### 学习统计

首页「学习统计」以今日学习时长为主指标，并提供近 30 天每日学习时长柱状图、近 30 天刷题数量，以及只按完整练习计算、可切换科目/子题库的正确率统计：

- **学习时长**：按今天累计，只在答题过程中计时。提交答案后阅读解析、切到其他标签页、打开弹窗或连续 90 秒没有操作都会暂停计时；练习设置页、总结页和首页停留不计入。柱状图展示近 30 天每天的时长，没有练习的日期为 0。学习时长从本次更新后开始记录，之前的历史没有时长数据。
- **刷题数量**：最近 30 天完成的作答次数，包含两种答题方式和简答题自评。
- **正确率**：只统计一次完整做完的练习，记录这一组题目的整体正确率（本组答对数 / 本组题数）。「全部题目」和「未掌握」范围的完整练习会计入；错题复习、收藏题目练习、指定题目练习、无限随机模式和中途退出都不计入，跳过题目导致没有全部作答的练习也不计入。首页卡片显示最近一次完整练习的正确率。
- **按范围汇总**：正确率面板默认打开最近一次完整练习所在的范围，显示该范围所有完整练习的总正确率（累计答对数 / 累计题数）；也可以切换科目或子题库。选择「科目总题库」时只汇总该科目总题库的完整练习，不会混入子题库成绩；选择子题库时只汇总该子题库的成绩。折线每次完整练习一个点，显示最近 30 次，不做跨次累计。每次只显示当前选择的科目或子题库。
- 把鼠标移到图上或聚焦数据点可以查看这是第几次完整练习、这组答对多少题和本组正确率，也可以展开「查看数据表」读取全部数值。
- 完整练习正确率从本次更新后开始记录；更早的逐题统计仍用于题目掌握度、错题状态和刷题数量，但无法还原当时一组练习的边界，因此不会进入新的正确率统计。中途退出练习时，已作答题目仍会更新题库统计和近 30 天刷题数量，但不会进入正确率记录。统计数据只保存在当前浏览器。

### 答题方式

- **每题查看答案**：单选/判断题点选选项后自动提交，立刻显示正确答案、对错和解析，按「下一题」继续。适合边做边学。
- **全部做完后查看**：答题过程中不显示对错或答案；单选/判断题点选后自动进入下一题，全部完成后统一显示正确率、答对/答错数量和错题答案。适合模拟测试。
- 多选题选择全部正确选项后点提交；填空题填写后按 Enter 或点提交。
- 使用随机顺序或无限模式时，选择题/判断题的选项顺序也会随机打乱并重新编号，页面会提示「选项顺序已打乱」。乱序只发生在当前练习中，不会修改题库里的选项和答案；按顺序练习时保持原顺序。
- 简答题填写后点「提交并自评」，程序会显示参考答案和解析；你选择「答对了」或「还需复习」后才计入统计。简答题没有唯一文本答案，参考答案仅供对照，可以留空，也不会由程序自动判分。
- 练习过程中可以点「上一题」回看之前的题目和已选项。已作答的题目不会重复计分。
- 答题方式会记住上次的选择，下一次进入练习设置时仍会保持。

### 无限模式

在练习设置的「题目数量」中选择 **∞ 无限**：

- 从当前题库范围的全部可练习题开始，打乱顺序持续出题，没有固定终点，也不会自动交卷。
- 一轮题刷完后会重新打乱并继续循环，同一道题可能再次出现。
- 只能点击「退出练习」手动结束；有作答记录时会先确认，并显示本轮正确率、答对/答错、用时（只计答题过程）和错题。
- 无限模式固定使用随机顺序和「每题查看答案」，因此不会出现“全部做完后查看”。
- 右侧进度点只显示最近 24 题；总出题数不受限制。
- 无限模式和 AI 侧栏的开关会记住上次选择，下次进入练习设置时保持不变。

### 练习中的 AI 侧栏

练习页右侧会常驻一个「AI 辅导」对话区，做题过程中可以随时提问：

- 可以让 AI 给提示、讲思路、分析错因、换一种讲法或出同类题；也可以直接输入自己的问题。
- 对话会结合当前题目、选项、答案、解析和你的作答状态。它不会看到图片，只接收文字。
- AI 只在点击快捷问题或发送消息时调用，不会在开始练习时自动产生模型费用。
- 切换题目或提交答案后，侧栏会保留聊天记录，并用新题目继续回答。
- 窗口较窄时，AI 面板会移到题目下方；点题目右上角的「AI 辅导」可定位到输入框。
- AI 侧栏是可选的：练习设置中的「AI 辅导」开关可以默认关闭侧栏；答题时也可以点侧栏右上角的关闭按钮隐藏，再点题目右上角的「显示 AI 辅导」重新打开。这个选择会被记住。
- 没有配置 AI 时，侧栏会显示配置入口，不影响刷题、本地 OCR 和题目解析；关闭侧栏时不会读取 AI 配置，也不会调用 AI。

键盘作答：`A`–`D` 或 `1`–`4` 选择选项，`Enter` 提交 / 下一题；简答题输入框内用 `Ctrl + Enter`（macOS 为 `Cmd + Enter`）提交并进入自评。

## 科目、子题库与总题库

题库按两层组织：

```text
总题库（所有科目）
├─ 科目 A
│  ├─ 科目 A 总题库
│  ├─ 子题库 A-1
│  └─ 子题库 A-2
└─ 科目 B
   ├─ 科目 B 总题库
   └─ 子题库 B-1
```

- 「总题库」汇总所有科目的题目；每个科目也有自己的「科目总题库」。
- 每个子题库、科目总题库、总题库都可以单独开始练习。
- 子题库默认按创建时间排序；拖动子题库左侧的拖动手柄可以自定义顺序，拖动结果会写入 Markdown 并保持。聚焦拖动手柄后也可以按上下方向键调整。
- 自定义顺序优先于创建时间，不会因为 Markdown 文件名按字符排序而出现「10」排在「2」前面的情况。
- 练习设置里可以选择题数，也可以选择「全部」把当前范围的题目一次刷完。
- 题目编辑弹窗里可以修改题目所属的科目和子题库。
- 「总题库」卡片固定在左侧；右侧科目与子题库列表有独立的最大高度，内容较多时只滚动科目区域，不会把页面撑得过长。滚动时科目标题保持可见。
- 删除科目或子题库前，需要先清空其中的题目；旧版本题目会自动迁移到「未分类科目 / 未分类题库」。

## Markdown 题库文件

创建科目和子题库后，程序会在项目下的 `题库保存/` 目录中建立科目文件夹；**每个子题库直接保存为该文件夹下的一个 `.md` 文件**：

```text
题库保存/
└─ 高等数学/
   ├─ .shuati-subject.json   隐藏的科目索引，用于保持题库 ID
   ├─ 第一章 极限.md
   └─ 第二章 导数.md
```

文件夹名就是科目名，Markdown 文件名就是子题库名。只要把符合格式的 `.md` 文件放入某个科目文件夹，应用启动或刷新时就会把它加入该科目。题目正文是可读的 Markdown，少量机器元数据放在 HTML 注释里：

```md
<!-- shuati:question:start -->
## 第 1 题 · 单选题

**题目**

当 x→0 时，sin x / x 的极限是多少？

**选项**

- A. 0
- B. 1
- C. ∞
- D. 不存在

**答案**

B

**解析**

这是重要极限。
<!-- shuati:question:end -->
```

这些文件就是系统积累的题库：

- 保存、编辑、移动或应用 AI 结果后，应用会自动重写对应的 Markdown 文件。
- 每次启动应用会扫描 `题库保存/`，科目来自文件夹，子题库来自其中的 `.md` 文件；练习时只从本地题库抽题，**不会调用 AI**。
- 可以直接在 `题库保存/` 中新建科目文件夹和放入新的题库 MD；重新载入后即可生成对应科目和子题库。
- AI 只用于导入新图片时的文字结构分析，不是刷题的前置条件。
- 可以手动修改题目文字、选项、答案和解析，然后在「数据备份」中点击「从磁盘刷新」重新读取；结构标记和 `<!-- shuati:... -->` 注释建议保留。Markdown 文件需使用 UTF-8 编码，非 UTF-8 文件会提示转码，不会被自动覆盖。
- 复制同一个受管子题库 `.md` 作为副本时，程序会为副本中的重复题目生成新 ID，不会静默丢弃副本内容。
- 简答题在 Markdown 中使用 `## 第 N 题 · 简答题` 标题，选项写为 `_（无选项）_`；参考答案或评分要点可选，写入 `**答案**` 后仅供练习时对照。
- 删除科目或子题库时只会清理程序管理的 Markdown 文件；同一文件夹中的图片、笔记等非管理文件会保留。
- 旧版浏览器题库会在第一次启动时自动写入新结构；源图片可以继续放在单独的 `题库导入/` 文件夹中，应用不会把它们当成题库。

## AI 逐图分析

AI 是可选增强，不影响本地 OCR 使用。处理顺序固定为：

```text
图片 1 → 本地 OCR → 图片 1 的独立文字 → AI 分析
图片 2 → 本地 OCR → 图片 2 的独立文字 → AI 分析
……
```

**AI 始终不接收图片。** 它只接收每张图片单独提取出的 OCR 文字，并在自己的文字范围内识别、纠错和拆分题目，不跨图片合并。

### AI 配置教学

AI 是可选的。没有配置 AI 时，本地 OCR、拆题、保存题库和练习都能正常使用；只有主动点击 AI 相关按钮才会调用模型并产生费用。

#### 第一步：准备 API Key

AI 分析需要一个支持 **OpenAI 兼容 Chat Completions 接口** 的普通对话模型。网页版聊天会员账号通常不能直接当 API 使用，需要到服务商的开发者控制台创建 API Key：

1. 登录所选服务商的控制台。
2. 找到「API Key」「密钥管理」或类似入口，创建一个新密钥。
3. 复制保存密钥；很多服务商只会在创建时完整显示一次。
4. 确认账号有可用额度或已绑定计费方式。
5. 确认服务商文档中提供了 **OpenAI 兼容接口地址** 和 **对话模型名称**。

本地模型（例如 LM Studio、Ollama）通常不需要 API Key 或计费，填写本地接口地址和模型名即可。不要把账号密码、网页登录 Cookie 或别人的共享 Key 填进这里。

#### 第二步：在应用中填写

1. 启动刷题助手，打开 `http://127.0.0.1:8765/`。
2. 点击左侧「AI 设置」。
3. 填写「接口地址」：
   - 可以填服务商提供的 base URL，例如 `https://api.openai.com/v1`。
   - 也可以直接填完整的 `/chat/completions` 地址。
   - 程序会自动补全常见的 `/chat/completions` 路径；远程服务请使用 `https://`。
4. 填写「API Key」。如果之前已经保存过，输入框留空会保留原密钥；本地模型不需要鉴权时可以留空。
5. 填写「模型名称」。必须是服务商提供的普通对话模型名称，不需要 OCR 模型，也不需要支持图片输入。
6. 可选：填写「运行规则与指导」，调整回答风格、术语偏好和核验习惯。
7. 点击「测试连接」。看到连接成功后点击「保存」。
8. 回到导入页，点击「AI 逐图分析」开始使用。

#### 第三步：确认调用方式和费用

- 程序会对每张图片分别执行：本地 OCR → 单独把这张图的文字发给 AI。**图片永远不会发给 AI。**
- 每轮 AI 分析前都会再次确认；AI 结果只进入预览，不会自动写入题库，需要你校对后保存。
- 失败页不会阻塞其他图片；可以点「重试失败项」只重试失败页面。
- 费用、限流和每日额度由你选择的服务商决定。建议先用几张图片测试，再批量导入。

#### 常见服务商示例

| 服务 | 接口地址示例 | 模型名称 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/chat/completions` | 例如 `deepseek-flash`，以服务商当前文档为准 |
| OpenAI | `https://api.openai.com/v1` | 按账号可用模型填写 |
| 阿里云百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 按服务商文档选择通义千问对话模型 |
| 智谱 AI | `https://open.bigmodel.cn/api/paas/v4` | 按服务商文档选择 GLM 对话模型 |
| 本地 LM Studio | `http://127.0.0.1:1234/v1` | 本地加载的对话模型 |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | 本地加载的对话模型 |

以上地址只演示格式，模型名称和服务商限制可能变化，请以服务商当前文档为准。DeepSeek 可以在 AI 设置里点「一键填入 DeepSeek 配置」，再填写自己的 API Key。

#### 常见配置问题

| 现象 | 可能原因和处理 |
| --- | --- |
| 401 / 403 | API Key 填错、已失效、没有权限，或账号/地区不支持；重新创建 Key，确认额度。 |
| 404 | 接口地址错误，常见原因是缺少 `/v1` 或把完整地址重复拼接；对照服务商文档检查。 |
| 429 | 请求过快、额度不足或触发限流；等待后重试，或换用额度更充足的模型。 |
| model not found | 模型名称拼写错误，或该账号没有这个模型的权限；使用服务商控制台显示的准确名称。 |
| 请求超时 / 网络错误 | 检查网络、代理和防火墙；远程服务优先使用 HTTPS，本地模型确认服务已经启动。 |
| 返回内容不是 JSON | 模型指令遵循能力不足或输出被截断；换用普通对话模型，减少单页文字长度后重试。 |
| 测试连接成功，但逐图分析失败 | 可能是单页文字过长、限流、额度或模型输出异常；查看对应图片文件卡片上的失败原因，只重试失败项。 |

#### 运行规则与指导（可选）

AI 设置中的自定义规则最多 8000 字，会附加到以下所有 AI 场景：

- 逐图文字分析
- 练习页 AI 辅导
- 全局 AI 助手
- 题库巡检和导入决策

适合写入回答风格、学科术语偏好、答案解析要求和核验习惯。自定义规则只能补充偏好，不能覆盖「AI 不接收图片」、来源真实性、动作白名单、数据修改确认等系统约束；冲突时以系统规则为准。规则只保存在本机 `ai-config.json` 中，不会进入题库备份。

#### API Key 安全

- API Key 只保存在本机项目的 `ai-config.json` 中，不会写入 Markdown 题库，也不会进入题库备份。
- `ai-config.json` 默认已被 `.gitignore` 忽略，不要截图、上传或发给别人。
- 如果密钥曾经泄露，请立即到服务商控制台撤销并重新创建。
- 远程模型会接收每张图片的文字内容；如果题目涉及隐私，建议使用本地模型，或不要使用 AI 分析。

### 逐图分析的特点

- 每张图片在列表里都有独立的 `AI 排队中 / AI 分析中 / AI 已分析 / AI 分析失败` 状态。
- 任意一张 AI 调用失败不会阻塞后续图片；失败页会在结果中单独标记。图片较多时会在请求之间留出间隔，服务商限流、临时 5xx 或网络中断会自动退避重试。
- 分析结束后如果仍有失败页，会显示「重试失败项 (N)」按钮，只重新发送失败图片的文字，不会重复调用已经成功的页面。
- 失败原因会显示在对应文件卡片上，并写入 AI 结果中的页面警告，便于判断是限流、超时、模型配置还是文字过长。
- 带页面警告、题目警告或置信度低于 70% 的 AI 题目，保存后会在题库列表显示黄色「AI 需复核」标记；标记会随 Markdown 保存。打开题目编辑可查看来源图片、警告和置信度，确认无误后可清除标记。
- 应用 AI 结果时只替换右侧题目预览，不直接写入题库；你仍然需要校对并点击保存。
- AI 看不到原图，所以无法独立验证 OCR 是否真的看错。提示词会要求它只根据文字纠正明显问题，不能确定的地方必须写入警告，不允许补造答案。

### 答案冲突与联网核验

当 OCR 文字中的题干、选项与标注答案出现明显冲突时，提示词要求 AI：

- 先在这张图片自己的文字范围内反复核对。
- 如果配置的模型或服务**本身支持联网搜索**，可以自主搜索简洁关键词，优先查证权威教材、标准和官方网站；来源名称或 URL 必须写入该题的警告。
- 只有检索证据明确支持时才允许修正答案，并在警告中写明原答案、冲突点和依据。
- 不能联网、搜索无结果或来源矛盾时，必须保留原答案、降低置信度并说明冲突；不得声称已经搜索，也不得编造来源。

注意：DeepSeek、OpenAI 的普通对话 API 默认不具备网页搜索能力；是否能真正联网取决于模型和服务商。若需要强制联网核验，需要选择带搜索能力的模型服务或单独接入搜索 API。使用带搜索能力的模型时，检索关键词会由该模型服务处理；图片仍然不会发送。

### AI 选项式互动

启用 AI 后，应用提供类似 Claude Code 的可点击选项交互：

- 右下角「AI 助手」：根据当前页面提供下一步操作选项，也可以直接文字提问。
- 刷题页右侧「AI 辅导」侧栏：AI 会根据当前题目给出“提示 / 讲解 / 错因分析 / 同类题”等动态选项，也可以自由输入问题。
- 题库页「AI 巡检」：根据缺答案、重复题、答案异常统计，提供查看筛选的选项。
- 导入结果页「让 AI 帮我决定」：AI 根据逐图分析结果给出应用、逐题查看或重新分析的选项。

AI 会动态生成选项，但选项动作受白名单约束；AI 不能直接删除、改写或保存数据。需要修改界面的动作由你在点击选项后执行，危险操作仍走应用自己的确认流程。

### AI 知识图谱（电脑端）

桌面端侧边栏新增「知识图谱」入口，用 AI 把一个**子题库**的题目归纳成树状思维导图：

- 选择子题库后点击「AI 生成图谱」。AI 只读取题干和解析文字，不发送图片、选项、答案或练习统计。生成请求以 JSON 结构发送，兼容模型返回的嵌套 `children` 树；没有关联到知识点的题目会放进「未归类题目」分支，不会因此让整张图生成失败。
- 每个知识点会关联真实题目；点击节点可以查看摘要、关键词、正确率，并直接练习该知识点。
- 节点颜色由本地练习统计实时计算：灰色未练习、红色薄弱、黄色一般、绿色掌握。刷题后不需要重新生成图谱。
- 生成结果以 JSON 保存在 `题库保存/.shuati-knowledge/<子题库ID>.json`。该目录是程序管理的隐藏目录，不会参与 Markdown 题库扫描，也不会被误认为科目或子题库。删除子题库时，同步流程会清理对应 JSON。
- 只有点击生成时才会调用 AI；生成结果会缓存，重新打开页面不会再产生费用。题库内容变化后页面会提示图谱可能过期，可以只重新生成该子题库。
- 点击顶部「导出知识图谱」可以把当前子题库的知识树导出为 JSON。文件包含子题库信息、知识节点和题目指纹；题目 ID 不同的设备会按题目内容自动重新关联。
- 安卓、苹果和离线版不调用 AI 生成图谱，但可以在「知识树」页面导入电脑端导出的 JSON。导入时会自动匹配本地子题库，并保留隐藏的知识节点与题目关联；知识树保存在当前设备，可在页面里按知识点练习。
- 单个子题库最多 300 道题、约 4 万字题干与解析；超过时建议先拆分子题库。

### 关于“周期”

当前实现是：点击一次「AI 逐图分析」后，在一个任务内按图片顺序循环处理，直到所有图片完成或跳过。它不是后台定时任务，也不会在你不操作时自动产生 API 费用。

如果你希望定时扫描图片文件夹（例如「题库导入/」）中的新图片并自动执行这条 AI 周期，需要另外确定目录、扫描间隔和失败重试策略，再接入后台定时任务。

### 安全与限制

- AI Key 和自定义运行规则保存在本机项目根目录的 `ai-config.json`，是明文本地配置文件，不会进入题库 JSON 备份。
- AI 只接收提取出的文字，不接收图片；普通 OCR 完全在本机运行。
- AI 可能拆错题或根据上下文“纠正”错字。应用前请检查置信度、警告和题目内容。
- 练习侧栏提问时，会发送当前题目的文字、选项、答案、解析和你的作答状态给 AI（不发送图片）；这些内容用于生成提示、讲解和错因分析。
- 如更换了服务商，建议在 AI 设置中重新填写 Key；不再使用时可删除 `ai-config.json`。

## 数据保存

- 科目、子题库、题目、答案和解析保存为项目 `题库保存/` 文件夹中的 Markdown 文件；科目对应文件夹，每个子题库对应一份独立 `.md` 文件。AI 复核警告、置信度和来源图片信息也保存在题目元数据中。
- AI 知识图谱单独保存在 `题库保存/.shuati-knowledge/` 下的 JSON 文件中，按子题库 ID 命名；它不参与 Markdown 题库扫描。电脑端可通过「导出知识图谱」导出单个子题库的知识树；移动端导入的知识树保存在当前设备的浏览器存储中，并随完整数据备份一起导出。
- 练习统计、错题状态和历史记录保存在**当前浏览器的本地存储**中，并按浏览器地址隔离；换浏览器或端口后题目仍在，但练习进度不会自动迁移。
- **图片本身不会被保存，也不会发送给 AI**。图片只交给本机 OCR；AI 只接收每张图片单独提取出的文字。
- 「数据备份」可以导出 / 导入包含科目、子题库、题目、练习记录和统计的完整 JSON；它是 Markdown 题库之外的额外备份。导入时内容相同的题目不会重复添加，并会合并备份中的练习统计和收藏状态。
- 在「数据备份」里点击「从磁盘刷新」可以重新读取手动修改过的 Markdown 文件。
- 清除浏览器数据只会影响练习统计和设置，不会删除 Markdown 题库；「清空数据」会同时清理程序管理的题库 Markdown 文件，但保留同目录下的图片等非管理文件。建议操作前先导出 JSON 备份。

## 识别说明与限制

- RapidOCR 对清晰的截图、白底印刷体效果最好。
- 彩色或小字号的孤立答案字母容易因置信度偏低被过滤；现在会保留疑似答案的低置信度字母和「正确 / 错误」文字，并过滤其余低置信度噪声。
- 手机作业截图中的时间栏、页码导航和「教师批阅」会自动忽略；「正确答案 C，我的答案：A」会提取 C 作为正确答案，不会用“我的答案”覆盖。全角答案字母也会自动转成半角。
- 手写体、艺术字、复杂公式、上下标、双栏排版可能需要手动校对。
- 数学公式目前按普通文本识别，建议在预览区手动修正。
- 单张图片最大 25MB，单批最多 100 张；超过 100 张时会提示未加入的数量，可以分批导入。
- 题目解析依赖题号、选项字母和「答案：」「解析：」等常见格式；格式特殊时可在预览中手动调整。

## 隐私

- 服务只绑定 `127.0.0.1`，不监听局域网；所有写接口只接受同源页面发起的 `application/json` 请求，拒绝其他网页的跨站调用。
- 普通识别时，图片只在 `POST /api/ocr` 中发送给本机 Python 服务处理，处理完不落盘。
- AI 永远不接收图片。导入时，只有每张图片单独 OCR 出的文字会经本机服务转发到你配置的普通对话模型服务；每轮发送前都有确认提示。
- 如果所选模型服务自带联网搜索，答案冲突核验时检索关键词会由该模型服务处理；程序本身不会另行上传题目或图片。
- 练习侧栏中只有你主动提问时才会调用 AI，发送当前题目的文字上下文和对话记录，不包含图片；不提问就不会产生调用。
- AI 设置中的自定义运行规则会作为系统提示的一部分发送给你配置的模型服务，并且只保存在本机 `ai-config.json`。
- AI 配置文件 `ai-config.json`（包含 Key 和自定义运行规则）只保存在本机，不进入题库备份。
- 没有账号、云同步或遥测。
