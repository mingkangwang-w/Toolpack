# 平板端验收清单

## 一、电脑端分享

- [ ] 电脑和平板连接同一个 Wi-Fi。
- [ ] 电脑打开「我的题库 → 分享给平板 → 开始分享」。
- [ ] 页面显示至少一个局域网地址和 6 位导入码。
- [ ] 点击「复制地址」「复制导入码」能够复制。
- [ ] 点击「停止分享」后，平板无法再读取题库。
- [ ] 关闭分享弹窗后分享仍继续；关闭刷题助手后分享停止。
- [ ] 等待 10 分钟，分享自动停止。

## 二、Android APK

- [ ] 把 `刷题助手-Android.apk` 传到 Android 平板并安装。
- [ ] 首次打开没有闪退，显示「导入题库，开始离线刷题」。
- [ ] 「我的题库 → 配置向导 → 选择 JSON 文件」可以导入本地题库。
- [ ] 「我的题库 → 配置向导 → 从电脑导入」可以输入地址和导入码并导入。
- [ ] 导入后题目、科目、子题库数量正确。
- [ ] 关闭 Wi-Fi 和移动数据，仍能打开 App 并刷题。
- [ ] 完成一组练习后，首页学习时长、刷题数量和正确率有变化。
- [ ] 在电脑端导出某个子题库的知识图谱 JSON，平板「知识树 → 导入知识树」可以显示节点并从知识点开始练习。
- [ ] 强制关闭 App 再打开，题库和统计仍然存在。
- [ ] 「数据备份 → 导出 JSON」可以下载备份。
- [ ] 找不到图片 OCR、AI 设置和 AI 辅导入口。

## 三、iPad PWA

- [ ] iPad Safari 打开 `https://电脑局域网IP:8443/install`。
- [ ] 能下载并安装本地 CA 描述文件。
- [ ] 「设置 → 通用 → 关于本机 → 证书信任设置」已开启完全信任。
- [ ] Safari 打开应用地址后没有证书警告。
- [ ] 分享 →「添加到主屏幕」成功。
- [ ] 从主屏幕打开应用，导入本地 JSON 题库。
- [ ] 「知识树 → 导入知识树」可以选择电脑端导出的 JSON 并显示知识节点。
- [ ] 开启飞行模式后，应用仍能打开和刷题。
- [ ] 关闭电脑上的局域网安装服务后，应用仍能打开。
- [ ] 重新联网并打开应用一次，版本可以更新。

## 四、iPad 独立 App（需要 Mac）

- [ ] 在 Mac 上运行 `npm install`。
- [ ] 在项目根目录运行 `bash ios/构建iPad版.sh`，`pod install` 成功。
- [ ] Xcode 打开 `App.xcworkspace`，选择正确的 Team。
- [ ] 连接 iPad 后可以 Run 安装。
- [ ] 首次打开允许「本地网络」权限。
- [ ] 本地文件导入和局域网导入都可用。
- [ ] 「知识树 → 导入知识树」可以选择电脑端导出的 JSON 并显示知识节点。
- [ ] 断网后仍可刷题，重启 App 后数据仍在。

## 五、数据与安全

- [ ] 分享题库时没有把 `ai-config.json` 或 API Key 发给平板。
- [ ] 平板清除数据/卸载前先导出了备份。
- [ ] Android 更新版本使用同一份签名密钥。
- [ ] 电脑 IP 变化后，PWA 会变成新的站点地址；需要重新安装或在新地址导入题库。
