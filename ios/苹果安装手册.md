# 刷题助手 · 苹果设备安装手册

适用于 **iPad**，iPhone 也可按同样步骤安装；界面主要按平板尺寸设计。

> APK 是 Android 安装包，**不能安装到 iPad/iPhone**。苹果设备需要 PWA 或 IPA。

---

## 一、先选择安装方式

| 方式 | 需要 Mac | 需要 Apple ID | 支持局域网导入 | 适合 |
|---|---|---|---|---|
| **A. iPad PWA** | 不需要 | 不需要 | 只支持本地 JSON 文件 | 没有 Mac，想马上用 |
| **B. iPad 独立 App** | 需要 | 免费或付费均可 | 支持本地文件 + 局域网 | 想要真正的 App 体验 |

---

# 方式 A：iPad 直接安装 PWA

PWA 是从 Safari 安装到主屏幕的网页应用。安装完成后可断网刷题，但它不是 App Store 应用。

## A1. 电脑准备

1. 电脑和平板连接同一个 Wi-Fi。
2. 打开项目文件夹，进入 `pwa` 文件夹，双击：

```text
pwa/局域网安装离线版.bat
```

3. 等待窗口显示类似地址：

```text
平板安装页：http://192.168.68.188:8080/install
应用地址：  https://192.168.68.188:8443/
```

安装页使用 HTTP，因此第一次打开不会出现证书警告；应用本身仍然使用 HTTPS。8080 被占用时，窗口会显示 8081 或其他端口，**以窗口实际显示为准**。

4. Windows 防火墙提示时，选择允许“专用网络”。
5. **保持这个黑色窗口打开**；关闭窗口安装服务就会停止。
6. 电脑通常会自动打开一个「安装二维码」页面。没有自动打开时，打开窗口显示的 `offline-certs/安装二维码.html`。

如果窗口显示多个地址，优先使用第一个；第一个打不开时再尝试下面列出的其他地址。

## A2. iPad 打开安装页

1. 用 iPad 的「相机」扫描电脑屏幕上的二维码。
2. 扫码后会打开类似地址：

```text
http://192.168.68.188:8080/install
```

3. 如果没有二维码，打开 **Safari**（不要用微信内置浏览器），手动输入窗口显示的 HTTP 安装页地址。
4. 安装页本身不需要证书；安装描述文件并开启信任后，再打开 HTTPS 应用地址。

## A3. 安装组合描述文件并信任证书

现在只需要安装一个组合描述文件，里面同时包含：

- 局域网 CA 证书；
- 刷题助手主屏幕图标。

### 安装描述文件

1. 在安装页点击：

```text
安装刷题助手
```

2. 如果 Safari 提示下载描述文件，选择“允许”。
3. 打开 iPad 的「设置」。
4. 在设置首页找到「已下载描述文件」并点击。
5. 点击右上角「安装」。
6. 输入 iPad 锁屏密码。
7. 再次点击「安装」，最后点击「完成」。

> 如果设置首页没有「已下载描述文件」，进入：
> 「设置 → 通用 → VPN 与设备管理」，在“已下载的描述文件”中找到它并安装。

### 开启完全信任

仅安装描述文件还不够，必须手动开启信任：

1. 打开「设置 → 通用 → 关于本机」。
2. 滑到底部，点击「证书信任设置」。
3. 找到「刷题助手局域网本地 CA」。
4. 打开右侧开关，确认「继续」。

完成后，Safari 访问 `https://电脑IP:8443/` 时不应再出现证书警告。

## A4. 打开主屏幕图标

组合描述文件通常会自动把「刷题助手」图标添加到主屏幕。

1. 回到 iPad 主屏幕，确认出现「刷题助手」图标。
2. 如果没有自动出现，用 Safari 打开根地址：

```text
https://192.168.68.188:8443/
```

3. 点击 Safari 顶部的分享按钮 →「添加到主屏幕」。
4. 名称建议保留「刷题助手」，点击「添加」。

## A5. 第一次打开并导入题库

1. 从主屏幕打开「刷题助手」。
2. 进入「我的题库 → 配置向导」。
3. 选择「准备文件」→「下一步：导入到平板」。
4. 点击「选择 JSON 文件」。
5. 选择电脑导出的题库 JSON 文件。

PWA 版支持从“文件”App 选择 JSON；**不显示从电脑局域网直接导入的入口**，这是 PWA 和独立 App 的区别。

导入后检查题目数量，点击「开始刷题」。

## A6. 断网验证

1. 打开控制中心，开启飞行模式。
2. 从主屏幕重新打开「刷题助手」。
3. 确认题库仍在，能正常答题、看统计。
4. 再做一道题，关闭应用后重新打开，确认统计仍在。

如果断网后打不开，通常是没有完成 Service Worker 缓存：

1. 关闭飞行模式。
2. 从主屏幕打开应用，保持联网完整加载一次。
3. 关闭应用，再开启飞行模式重试。

## A7. 更新 PWA

电脑 IP 不变时：

1. 电脑重新运行 `pwa/局域网安装离线版.bat`。
2. iPad 联网打开一次应用，等待新版本缓存。
3. 之后可以继续断网使用。

如果电脑 IP 改变，PWA 会被 iPad 当成新站点，看不到旧的本地数据。建议：

- 在路由器里给电脑保留固定 IP；
- 或在更换 IP 前，先在应用「数据备份」中导出 JSON。

## A8. PWA 注意事项

- 只从自己电脑的安装页安装证书；不要安装来源不明的描述文件。
- 证书私钥保存在电脑的 `offline-certs/`，不要发给别人。
- 如果以后不再更新，可以在 iPad「设置 → 通用 → VPN 与设备管理」中删除描述文件；已安装的应用通常仍可离线打开，但无法再更新。
- 卸载 PWA、换浏览器或清除网站数据会丢失本地题库和统计，操作前先导出备份。

# 方式 B：构建 iPad 独立 App

需要一台 Mac。Windows 不能生成可安装的 IPA。

## B1. 准备环境

在 Mac 上安装：

1. **Xcode**：从 Mac App Store 安装，至少 Xcode 15。
2. **Node.js 20+**。
3. **Python 3.10+**。
4. **CocoaPods**：

```bash
brew install cocoapods
# 或 sudo gem install cocoapods
```

如果是 Apple Silicon Mac，优先使用 Homebrew 安装 CocoaPods。

## B2. 复制工程

把以下文件复制到 Mac：

```text
ios/release/刷题助手-iPad-工程.zip
```

解压后进入工程目录，确认能看到：

```text
ios/
web/
offline/
dist-offline/
build_offline.py
capacitor.config.json
package.json
构建iPad版.sh
构建iPad版.md
```

## B3. 安装依赖并生成 Xcode 工程

在工程目录执行：

```bash
npm install
```

然后执行：

```bash
# 在 iPad 工程包根目录
bash 构建iPad版.sh

# 如果在完整项目根目录
bash ios/构建iPad版.sh
```

脚本会依次完成：

1. 构建 `dist-offline/` 离线网页；
2. 执行 `npx cap sync ios`；
3. 执行 `pod install`；
4. 打开 `ios/App/App.xcworkspace`。

也可以手动执行：

```bash
python3 build_offline.py
npx cap sync ios
cd ios/App
pod install
open App.xcworkspace
```

> 打开的必须是 `App.xcworkspace`，不是 `App.xcodeproj`。如果只打开 `.xcodeproj`，通常会缺少 Capacitor 依赖。

## B4. Xcode 签名

1. 在 Xcode 左侧选择 `App` target。
2. 打开 **Signing & Capabilities**。
3. 勾选 **Automatically manage signing**。
4. **Team** 选择你的 Apple ID/开发者团队。
5. 如果提示 Bundle Identifier 已被占用，把 `com.shuati.helper` 改成唯一值，例如：

```text
com.你的名字.shuati
```

6. 确认没有红色签名错误。

## B5. 安装到 iPad

1. 用数据线连接 iPad 和 Mac。
2. iPad 上如果提示“信任此电脑”，选择信任并输入密码。
3. 在 Xcode 顶部设备列表选择你的 iPad。
4. 点击运行按钮（Run）。
5. 第一次运行可能提示开发者证书未信任：
   - iPad 打开「设置 → 通用 → VPN 与设备管理」；
   - 找到你的 Apple ID/开发者证书；
   - 点击「信任」。
6. 回到主屏幕，打开「刷题助手」。

### 首次打开允许本地网络

如果要使用「从电脑导入」，iPad 会询问是否允许访问本地网络：

```text
允许「刷题助手」查找并连接本地网络中的设备？
```

选择「允许」。

如果不小心拒绝：

```text
设置 → 隐私与安全性 → 本地网络 → 刷题助手 → 打开
```

## B6. 导入题库

独立 App 支持两种方式：

### 本地文件导入

1. 电脑「我的题库 → 导出题库」，得到 JSON。
2. 通过 AirDrop、iCloud Drive、微信或数据线传到 iPad。
3. App 中打开「我的题库 → 配置向导 → 选择 JSON 文件」。

### 局域网从电脑导入

1. 电脑和平板连接同一个 Wi-Fi。
2. 电脑打开「我的题库 → 分享给平板 → 开始分享」。
3. 记下电脑显示的地址和 6 位导入码。
4. iPad App 打开「我的题库 → 配置向导 → 从电脑导入」。
5. 输入地址和导入码，点击「从电脑导入」。

如果连接失败：

- 确认电脑和平板在同一 Wi-Fi；
- 确认 iPad 已允许本地网络权限；
- 允许 Windows 防火墙的“专用网络”访问；
- 尝试分享弹窗中列出的其他地址。

## B7. 免费 Apple ID 与长期使用

### 免费 Apple ID

- 可以直接用 Xcode 安装到自己的 iPad。
- 通常 **7 天后证书失效**，应用无法打开。
- 重新用 Xcode 运行一次即可恢复；题库数据通常仍保留。
- 不适合长期分发给其他人。

### 付费 Apple Developer

- 可以长期安装、使用 TestFlight 或 Ad Hoc 分发。
- 需要 Apple Developer Program 账号。
- TestFlight 适合让其他人测试；Ad Hoc 需要收集设备 UDID。

## B8. 更新独立 App

网页或功能更新后，在 Mac 上重新执行：

```bash
python3 build_offline.py
npx cap sync ios
cd ios/App
pod install
```

然后在 Xcode 中重新运行或 Archive。

更新时必须保持：

- 同一个 Bundle Identifier；
- 同一套签名证书。

否则 iPad 可能把它当成另一个 App，或者要求先卸载旧版。

## B9. 数据与卸载

- 题库、收藏、练习记录和统计保存在 iPad App 本地。
- 卸载 App 会删除这些数据。
- 更新覆盖安装通常保留数据。
- 建议定期在「数据备份 → 导出 JSON」中备份。

# 三、两种方式怎么选

## 没有 Mac

选 **PWA**：

- 不需要 Apple ID；
- 不需要 Mac；
- 安装一次证书即可；
- 支持本地 JSON 导入；
- 不支持 App 内的“从电脑导入”入口。

## 有 Mac

选 **独立 App**：

- 真正的 iPad 应用；
- 支持本地文件和局域网导入；
- 可以长期签名、TestFlight 分发；
- 需要 Xcode、CocoaPods 和 Apple 签名。

# 四、常见问题

## 1. iPad 能装 APK 吗？

不能。APK 只适用于 Android。iPad 需要 IPA 或 PWA。

## 2. Safari 提示证书不受信任

重新检查：

- 描述文件是否安装完成；
- 「设置 → 通用 → 关于本机 → 证书信任设置」是否开启完全信任；
- 是否访问的是电脑窗口显示的正确 IP 和端口。

## 3. 安装页打不开

- 电脑和平板是否在同一 Wi-Fi；
- 电脑安装窗口是否仍然打开；
- 地址是否使用窗口显示的 IP 和安装页端口（8080 或窗口显示的其他端口）；
- Windows 防火墙是否允许 Python/刷题助手的专用网络访问；
- 平板 VPN 是否拦截了局域网访问。

如果 HTTP 安装页无法下载描述文件，可以在电脑窗口显示的 HTTPS 应用地址后加 `/install`，例如：

```text
https://192.168.68.188:8443/install
```

接受一次证书警告后，可以用 HTTPS 备用安装页下载描述文件。

## 4. 添加到主屏幕后打开空白

- 先联网从主屏幕打开一次，等待 Service Worker 缓存完成；
- 检查是否有证书警告；
- 关闭后重新打开；
- 仍然失败时，删除主屏幕图标，重新从 Safari 安装。

## 5. Xcode 报 Bundle Identifier 冲突

把 `com.shuati.helper` 改成你自己的唯一标识，例如：

```text
com.yourname.shuati
```

## 6. pod install 失败

```bash
brew install cocoapods
cd ios/App
pod repo update
pod install
```

## 7. 应用 7 天后打不开

免费 Apple ID 的签名过期。连接 Mac，用 Xcode 重新运行一次。

## 8. 局域网导入失败

- 电脑分享是否仍在进行；
- 地址和导入码是否输入正确；
- iPad 本地网络权限是否开启；
- 电脑防火墙是否允许局域网访问。
