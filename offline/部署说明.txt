刷题助手 · 平板离线版（PWA）
================================

一、方式 A：局域网安装（不需要外网）
1. 电脑和平板连接同一个 Wi-Fi / 局域网。
2. 电脑双击「局域网安装离线版.bat」。
   脚本会启动 HTTP 安装页和 HTTPS 应用服务，并自动打开电脑上的
   「安装二维码」页面。窗口中会显示类似：
   平板安装页：http://192.168.x.x:8080/install
   应用地址：  https://192.168.x.x:8443/
   8080 被占用时会自动改用 8081 等端口，以窗口为准。
3. 用 iPad 相机扫描电脑上的二维码，或手动在平板浏览器打开 HTTP 安装页。
   安装页使用 HTTP，第一次打开不会遇到证书警告。
4. iPad / iPhone 点击「安装刷题助手」：
   组合描述文件同时包含本地 CA 证书和主屏幕图标；
   安装后到「设置 → 通用 → 关于本机 → 证书信任设置」开启完全信任。
   主屏幕通常会自动出现「刷题助手」；没有出现时用 Safari 打开 HTTPS
   应用地址，再通过分享按钮「添加到主屏幕」。
   Android 则在 HTTP 安装页下载 CA 证书，在
   「设置 → 安全 → 加密与凭据 → 安装证书」中安装，再在 Chrome 打开
   HTTPS 应用地址并选择「安装应用」/「添加到主屏幕」。
5. 安装并缓存完成后，关闭电脑上的安装服务并断网，平板仍可刷题。

注意：
- 本地证书只用于电脑的局域网安装地址，不包含题库内容。
- 证书私钥保存在电脑的 offline-certs 目录，不要分享给他人。
- 建议在路由器中给电脑保留固定 IP；IP 变化后平板会把它当成新站点，
  原有的本地练习数据仍在旧地址下，但新地址看不到。
- 如果平板打不开，请检查电脑防火墙是否允许 Python 的专用网络访问
  （安装页端口和 8443 端口）。

二、方式 B：部署到 HTTPS 静态站点
1. 把本文件夹中的全部文件上传到一个 HTTPS 静态站点。
   可以是 GitHub Pages、Cloudflare Pages、自己的 HTTPS 服务器或 NAS。
   不需要后端和数据库，也不会把题库上传到服务器。
2. 平板用浏览器打开该 HTTPS 地址，等页面完整加载一次。
3. 按上面的方式添加到主屏幕 / 安装应用。
4. 安装完成后可以断网使用。

三、导入题库
1. 在电脑端打开「我的题库 → 导出题库」。
2. 勾选需要的科目或子题库，点击「导出为一个文件」。
3. 把 JSON 文件发送到平板（微信、网盘、AirDrop、数据线均可）。
4. 平板打开「我的题库 → 导入题库 → 选择 .json 文件」。

四、数据说明
- 题目、收藏、练习记录和统计只保存在平板的浏览器中。
- 清除网站数据、卸载 PWA 或更换浏览器会导致本地数据丢失。
- 建议定期使用「数据备份 → 导出 JSON」保存备份。
- 平板和电脑的练习统计各自独立，通过 JSON 文件手动合并。
- 离线版不支持图片 OCR、AI 辅导、Markdown 导入和 Markdown 磁盘同步。

五、更新
局域网方式：让电脑 IP 保持不变，重新运行「局域网安装离线版.bat」，
平板在同一地址联网打开一次，新的 Service Worker 会更新缓存。
静态站点方式：重新上传新版本文件到同一个 HTTPS 地址。
