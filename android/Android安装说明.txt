刷题助手 · Android 平板安装说明
================================

一、安装
1. 把「刷题助手-Android.apk」传到 Android 平板（数据线、微信、网盘均可）。
2. 在平板文件管理器中点击 APK。
3. 如果提示“不允许安装未知应用”，按提示允许当前文件管理器安装应用。
4. 安装完成后，从桌面打开「刷题助手」。

二、导入题库（两种方式，任选一种）
方式 A：本地文件（不需要网络）
1. 电脑打开「我的题库 → 导出题库」。
2. 勾选需要的科目或子题库，点击「导出为一个文件」。
3. 把 JSON 文件传到平板。
4. 平板打开 App →「我的题库 → 配置向导」→「选择 JSON 文件」。

方式 B：局域网从电脑导入（只有导入时需要 Wi-Fi）
1. 电脑和平板连接同一个 Wi-Fi。
2. 电脑打开刷题助手 →「我的题库」→「分享给平板」→「开始分享」。
3. 记下页面显示的电脑地址和 6 位导入码。
4. 平板打开 App →「我的题库 → 配置向导 → 从电脑导入」，
   输入地址和导入码，点击「从电脑导入」。
5. 导入完成后在电脑上点「停止分享」，平板可断开网络刷题。

如果电脑上没有打开网页界面，也可以双击 `tools\题库分享给平板.bat`，
使用命令行方式启动同样的只读分享服务。

三、数据说明
- 题库、收藏、练习记录和统计只保存在平板 App 内部。
- 卸载 App 或清除应用数据会丢失本地数据。
- 建议定期在「数据备份 → 导出 JSON」中保存备份。
- 平板和电脑的练习统计各自独立，通过 JSON 文件手动合并。
- 离线版不支持图片 OCR、AI 辅导和 Markdown 磁盘同步。

四、更新
使用同一份签名密钥重新构建的 APK 可以直接覆盖安装，数据会保留。
如果更换了签名密钥，Android 会要求先卸载旧版，本地练习数据也会一起丢失。
